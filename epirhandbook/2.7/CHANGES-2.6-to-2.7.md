# Moved

The 2.6 → 2.7 change notes now live in the handbook repository, as the "2.6 → 2.7" section of:

**https://github.com/appliedepi/epirhandbook/blob/main/STAKEHOLDERS.md**

They were written for readers, authors and translators — the document is literally titled "what
changes for readers and authors" — and none of those people were ever going to look for them in an
infrastructure repository. They belong with the content.

The file was renamed from `CHANGES-2.6-to-2.7.md` to `STAKEHOLDERS.md` when it became cumulative:
one living document with a section per release, newest first, rather than a new file each upgrade
that readers would have to know to go looking for.

The translator backlog that used to be Part E is at
[TRANSLATION-BACKLOG.md](https://github.com/appliedepi/epirhandbook/blob/main/TRANSLATION-BACKLOG.md)
in the same repository, expanded with per-item instructions and an appendix of the site's
pre-existing dead anchors.

Nothing about the *build* moved. The image catalog, the package lists, the render scripts and the
reasoning behind them stay here — see `README.md` in this directory, and the repository root
`README.md` for how images are built and published.
